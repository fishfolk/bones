fn apply_inputs(&mut self, world: &World)

Update the internal state with the World.

This should be called every render frame / cpu cycle after input events.

Source

fn advance_frame(&mut self)

Indicates to the collector that its input has been consumed.

This should be called on frame update when input for this frame has been consumed as opposed to the cpu cycle. In a network session, by the time this is called, the dense input should be sent across the network.
