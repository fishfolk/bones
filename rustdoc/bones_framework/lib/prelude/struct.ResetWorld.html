Struct ResetWorld 

Source 
pub struct ResetWorld(pub HashSet<SchemaId, BuildHasherDefault<FxHasher>>);
Expand description

Convenience type for selecting resources to keep before clearing the components, entities, and resources on a World.

ⓘ
ResetWorld::standard()
   .keep::<Scoreboard>()
   .keep::<WritingRust>()
   .keep::<TheBugsAway>()
   .reset(world);

Reseting the world should likely be the first call in your systems when applicable so that components are rendered continuously without disappearing for a frame before respawning world startup components.

You can create the type with Self::standard, which is recommended for keeping certain special resources like SessionOptions & Entities on creation, or you can use Self::empty to create a new type that won’t keep any resources on creation.

To add more resources to the list you can use self.keep with the specified type, no data needed, and chain the methods like the example above.

Uses a HashSet of SchemaId to determine the resources that will not be removed from the world on reset.

pub fn entry(&mut self, value: T) -> Entry<'_, T, S, A>

Gets the given value’s corresponding entry in the set for in-place manipulation.

§Examples
use hashbrown::HashSet;
use hashbrown::hash_set::Entry::*;

let mut singles = HashSet::new();
let mut dupes = HashSet::new();

for ch in "a short treatise on fungi".chars() {
    if let Vacant(dupe_entry) = dupes.entry(ch) {
        // We haven't already seen a duplicate, so
        // check if we've at least seen it once.
        match singles.entry(ch) {
            Vacant(single_entry) => {
                // We found a new character for the first time.
                single_entry.insert()
            }
            Occupied(single_entry) => {
                // We've already seen this once, "move" it to dupes.
                single_entry.remove();
                dupe_entry.insert();
            }
        }
    }
}

assert!(!singles.contains(&'t') && dupes.contains(&'t'));
assert!(singles.contains(&'u') && !dupes.contains(&'u'));
assert!(!singles.contains(&'v') && !dupes.contains(&'v'));

pub fn insert_unique_unchecked(&mut self, value: T) -> &T

Insert a value the set without checking if the value already exists in the set.

Returns a reference to the value just inserted.

This operation is safe if a value does not exist in the set.

However, if a value exists in the set already, the behavior is unspecified: this operation may panic, loop forever, or any following operation with the set may panic, loop forever or return arbitrary result.

That said, this operation (and following operations) are guaranteed to not violate memory safety.

This operation is faster than regular insert, because it does not perform lookup before insertion.

This operation is useful during initial population of the set. For example, when constructing a set from another set, we know that values are unique.
